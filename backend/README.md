# ReconGrid AI Backend

Autonomous settlement reconciliation and discrepancy-diagnostic engine for Razorpay merchants.

## Features
- Autonomous multi-tiered reconciliation engine (Exact match, fee/tax deductions, fuzzy UTR matching)
- PostgreSQL and SQLite database engine support with Alembic migrations
- FastAPI asynchronous REST API
- LLM-powered settlement Q&A and discrepancy diagnostic assistant
