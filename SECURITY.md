# Security Policy

## Supported Versions

ReconGrid-AI does not currently have any published releases or versioned packages.

Currently, the project supports the latest state of the `main` branch with security updates.

| Version | Security Support |
| ------- | ---------------- |
| `main`  | :white_check_mark: |

Once official releases are published, this section will be updated to list the supported release versions.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

To report a vulnerability privately, contact the project maintainer at:

**akshayhaldar.dev@gmail.com**

If GitHub's private vulnerability reporting feature is enabled for this repository, you can also use the **Report a vulnerability** option in the **Security** tab to submit a report privately.

When reporting a vulnerability, please include:

- A clear description of the vulnerability.
- The affected component or file, if known.
- Steps to reproduce the issue.
- The potential impact.
- Any proof-of-concept details that can help reproduce the issue safely.

### Response Targets

The project aims to:

- Acknowledge receipt of a vulnerability report within **2 business days**.
- Provide an initial assessment or response within **5 business days**.

These are response targets rather than guarantees. Complex vulnerabilities may require additional investigation time.

## Responsible Disclosure

Please allow the maintainers reasonable time to investigate the report, develop a fix, and coordinate disclosure before making vulnerability details public.

Security vulnerabilities should not be disclosed publicly or submitted as public GitHub issues before the maintainers have had an opportunity to address them.

If an embargo or coordinated disclosure date is appropriate, the reporter and maintainers can agree on a suitable timeline.

## Accidentally Committed Credentials or Secrets

If you accidentally commit a password, API key, access token, private key, or other sensitive credential:

1. Do not create a public issue or pull request containing the secret.
2. Contact **akshayhaldar.dev@gmail.com** privately as soon as possible.
3. If you have access to the affected service, revoke or rotate the credential immediately.
4. Do not share the exposed secret in your report or in any public discussion.
5. The maintainers will assess the exposure and determine appropriate cleanup and remediation steps.

Removing a secret from a later commit does not necessarily remove it from the repository's Git history, so exposed credentials should be treated as compromised and rotated or revoked.

## Scope

This policy covers security vulnerabilities affecting ReconGrid-AI and its repository, source code, dependencies, and documented application functionality.

Thank you for helping keep ReconGrid-AI and its users secure.
